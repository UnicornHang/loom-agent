# 通用模型配置（开发阶段）

管理员在「Agent 配置」添加或编辑连接名称、HTTPS API 基础地址、模型名称、API Key、能力类型、Token 价格、币种和启用状态。已接入 OpenAI 兼容文本及嵌入协议；视觉、图片、语音及其他协议需单独适配，不能仅凭填写地址保证兼容。

- API：GET/POST `/api/v1/model-connections`，PUT `/api/v1/model-connections/{id}`。
- 仅管理员可访问，修改需要 CSRF 校验；连接按租户隔离。
- 密钥使用 Fernet 加密后入库；列表和保存响应均不返回明文或密文。
- 编辑时留空保留原密钥；启用表示允许后续使用，不代表连接测试成功。
- 开发环境首次保存时生成 `backend/.secrets/model.key`，独立备份该文件与数据库。丢失该文件将无法解密已有连接。此目录不进入 Git 或 Docker 构建上下文。
- 云部署必须将加密密钥放入持久化的受限目录或密钥管理服务，不可依赖容器临时文件系统。

## Agent 独立配置

「Agent 管理」覆盖八类 Agent，分别保存主备模型、Prompt、变量预览值、温度、输出 Token、超时、重试、并发、循环上限、工具调用上限、单次预算、Skill 正文及版本标识、内部工具白名单。

每次保存创建不可覆盖的草稿版本，携带 base_version 防止并发覆盖；历史版本可载入编辑并另存为新版本。配置仅管理员可读写，按租户隔离。创作子图已使用发布版本并固定输入、连接与产品快照；执行循环、Token、预算和超时限制。工具白名单目前不能用于实际工具调用；配置含工具时会明确阻断测试。自动重试次数尚未完整接入，未知调用结果不会自动重复计费。

API：GET/POST `/api/v1/agent-configs/{agent_type}`；POST `/api/v1/agent-configs/{agent_type}/validate`。静态校验检查主备模型是否启用、Prompt 是否为空及变量是否齐全，返回变量替换预览；不发送模型请求。

## 测试、发布和预算

保存版本后，POST `/agent-configs/{agent_type}/{id}/test` 对所选主备文本模型做真实响应测试；需要配置公司每日预算、单次预算和模型价格。POST `.../{id}/publish` 校验测试指纹与预期生效版本；连接、模型、价格或密钥变化后，旧测试不再有效。历史版本重新发布即回滚，不覆盖其正文。连通测试不等于业务输出质量验收。

每日预算按北京时间统计，金额使用百万分之一币种的整数记账。调用前预留，返回用量后按管理员提供的价格结算；失败或用量未知时保留额度待核对。公网 HTTPS 请求校验 DNS 地址并固定实际连接 IP，保留证书主机校验，禁止跟随重定向，限制大小与超时。摘要日志不记录密钥和原始供应商错误正文。

## Skill、MCP 和推荐

Skill 版本库支持方法模板保存、声明变量、静态校验发布与绑定。绑定时以服务端发布正文为准；每次运行仍使用 Agent 配置中固定的 Skill 快照。

MCP 支持服务登记、凭据替换或清除、公网 Streamable HTTP 工具发现。配置修改后旧发现结果失效。当前没有 tools/call，不因发现工具而自动授权业务数据出站。

推荐检索另行选择嵌入连接及单次预算，产品维护者在产品编辑页建立索引。产品事实使用普通数据库；向量用于召回，推荐 Agent 文本模型用于种草适配评分。尚需公司标注样本校准阈值与推荐质量。

真实供应商联调尚未执行；自动测试采用受控响应。更多实现边界见《开发进度与验收记录.md》。
