# 开发进度与验收记录

更新日期：2026-11-22。本文记录当前代码事实，不替代 PRD 的上线验收标准。

## 本轮已实现并回归的功能

1. 产品资料维护：编辑描述、名称和品类；草稿、启用、归档状态；授权检查、并发修改冲突；名称、SKU、品类搜索。
2. 工作流资料：正文或视频文字稿确认、素材使用权限确认、授权产品选择、无产品继续、产品事实快照；素材变化使下游草稿失效。
3. 内容版本：三种文章候选的数据结构、人工逐段编辑、历史版本、确认保存、内容库、Markdown 下载；图片占位上传后保存新版本，图文 ZIP 包含正文和本地图片。
4. 通用模型：OpenAI 兼容文本与嵌入接口；密钥加密；主备连接测试；模型能力与价格；每日预算、调用预留和用量结算。调用失败或未知用量保留预估额度，不能冒称已退款。
5. Agent 配置：独立 Prompt、变量、参数和限制；草稿不可覆盖；真实文本测试后发布；历史版本重新发布可回滚。连接或密钥变化使旧测试失效。
6. Skill：版本库、适用 Agent、行业和变量声明；方法模板发布；绑定时从服务端读取已发布正文并固化到 Agent 配置。模板发布不是模型质量测试，也不允许执行脚本。
7. 后台创作：Celery Worker、调度器与数据库 outbox；LangGraph 生成、自检、有限修订子图；PostgreSQL 检查点；输入及连接快照；三篇文章或一份剧本候选。局部改写检查非目标段落逐字不变。
8. 人工边界与日志：候选不自动成为成果；任务创建幂等；取消任务；真实事件、SSE 游标续传、权限重检；模型和预算配置审计。
9. 按需审核：发布的审核 Agent 可审核当前文本版本；结果包含原文引用与问题建议；新版本不继承旧审核。当前是文本审核，不能当作图片、视频画面审核或合规保证。
10. 视频 P0：确认剧本后进入分镜；分镜包含景别、运镜、构图、时长，总时长30–60秒；剧本和分镜确认后导出。不生成成片，画面草图当前是描述及人工上传图片。
11. 采集配置：行业、关键词、间隔、启停、配置冲突、手动和定时预检日志。用户已确认暂未取得授权，因此当前不发起平台请求，也不向大厅填充模拟热点。
12. MCP：加密凭据、登记与修改、超时和计划出站范围；公网 HTTPS Streamable HTTP 初始化与工具发现，支持 JSON/SSE 响应。只读发现，不执行工具；计划范围尚不是可执行授权。
13. 聊天式工作流入口：一次事务创建参考内容、工作流和素材确认；按内容类型进入下一步骤；重复请求返回原记录，不重复建任务。
14. 混合推荐：产品事实仍在业务数据库；授权 SQL 过滤后，以关键词及向量召回最多30条，文本 Agent 按种草适配重排，结果最多10条，支持65/60门槛与授权搜索兜底。产品变更使旧向量失效。分数是待校准建议，不是转化概率。

## 验证证据与边界

- 当前自动测试：15项，涵盖多个 API 场景、权限、CSRF、迁移、结构校验、版本、预算、图运行、审核、MCP 协议和推荐。API 主回归是一项集成测试，不能把“15项”理解为仅15个接口断言，也不能理解为所有 PRD 用例已通过。
- 前端 TypeScript 检查及生产构建通过；Docker 前端构建已在前述阶段验证。仍存在大体积打包告警，需要进一步拆分页面和依赖。
- 在开发 PostgreSQL 中实际执行授权 pgvector 余弦查询，测试数据事务回滚；检查点表实际初始化成功。
- Worker 和调度器已启动，实际 outbox 调度日志正常；新代码需重启 Worker，前端挂载使用轮询检测变更。
- 模型、嵌入、审核及 MCP 自动测试使用受控响应，不代表已连接任何真实供应商。未替用户填写 Key 或开通付费服务。
- 目前向量用 JSON 保存，PostgreSQL 查询时转为 vector 做授权范围内精确计算，SQLite 仅作为测试回退。首期小规模采用精确检索，尚未建立 ANN 索引；产品索引取前12000字符、参考查询取前6000字符，需用实际资料评估召回。

## 后续联调顺序

管理员添加文本和嵌入连接并填写价格 → 配置预算 → 测试并发布文章、编剧、分镜、审核和推荐 Agent → 在产品编辑中建立索引 → 聊天入口提交有权素材 → 推荐或搜索产品 → 生成、局部修改、配图、可选审核与确认下载。外部来源授权取得后再接真实采集，不需要重写现有业务流程。
