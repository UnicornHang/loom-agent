# 数据采集第一版：抖音公开热搜

本版范围按用户2026-11-22的最新决定调整：先采集通用公开热榜，不做指定行业、品类、种草意图或作品正文分析。

## 当前实现

- Python 适配器：`backend/app/collectors/douyin_hot.py`。
- 固定读取抖音网页的公开热搜列表，只提取话题标题、稳定标识、排名、可获得的热度和话题链接。响应大小、超时和条数受限，不自动跟随重定向，不保存账号 Cookie。
- 标注为热搜话题，`material_available=false`。没有取得完整文章、笔记或视频；进入创作时仍需补充有权使用的素材。
- 以租户、来源类型和话题标识去重。同一话题再次出现时更新热度与采集时间，不重复创建大厅记录；旧话题保留原采集时间，不冒充当前仍在榜。
- 手动采集和每分钟检查一次的定时调度共用任务队列。每个来源最短间隔15分钟，默认60分钟；队列待发送记录保存在数据库，重复任务不重复入库。
- `collector` 容器消费 `collection,control` 队列，创作 Worker 消费默认队列，长时间创作不会占用采集 Worker。
- 配置变化时过期任务不入库。HTTP 403/429、无效响应、格式变化和网络失败均记录真实原因，不切换到占位或模拟数据，不自动绕过验证码或访问限制。

## 页面与接口

管理员打开「采集来源」→ 选择「抖音公开热搜（V1）」→ 保存 →「立即采集」或启用定时执行。行业和关键词字段当前仅保存，V1不用于过滤全站热搜。

- POST `/api/v1/sources/{id}/run`：提交后台任务；已有活动任务时返回同一任务。
- GET `/api/v1/sources/{id}/runs`：查看 queued、running、succeeded、empty、failed、blocked、stale 状态及新增／更新数量。
- GET `/api/v1/hotspots`：返回来源标识、热度、排名与采集时间。热点大厅已区分手动导入和抖音自动采集。

开发环境通过 `docker compose up -d --build` 启动，需要 API、Redis、scheduler 和 collector。首次试采在开发租户下创建一条默认每小时执行的来源，可在页面停用或调整间隔。

## 验证

- 编写代码前已在开发容器实测网页接口：HTTP 200、有效 JSON、49条热搜话题。
- 自动测试覆盖解析、重复条目、空榜与异常格式区别、限流、重复任务、跨租户去重、配置过期、入库及更新；合计21项后端测试通过，前端构建通过。
- 最终后台任务的真实条数以「采集来源」日志为准，不能用前述接口测试条数冒充任务完成条数。
- 首轮完整后台任务已实测成功：收到49条、有效49条、新增49条、更新0条，开发租户数据库确认入库49条。后续批次可能新增或更新其他话题，以各批次日志为准。

## 本版未包含

小红书采集、抖音关键词作品搜索、原视频或笔记正文下载、按行业筛选、种草识别和两周覆盖率评估。网页接口可能变化，后续按真实失败日志维护适配器。

参考了 [daily-hot-mcp 抖音模块](https://github.com/fancyboi999/daily-hot-mcp/blob/main/daily_hot_mcp/tools/douyin.py) 的公开接口线索，本项目独立实现采集适配、持久化、队列、隔离和日志。


## 2026-11-22 多来源扩展

参考 [daily-hot-mcp](https://github.com/fancyboi999/daily-hot-mcp) 的公开接口线索独立实现，未引入 MCP 服务依赖。新增来源注册表 `backend/app/collectors/registry.py` 和适配器 `public_boards.py`，复用现有后台任务、租户隔离、去重、配置版本检查和日志。无需新增数据库迁移。

- 微博热搜：标题、排名、热度、搜索链接，过滤广告。
- B站热门：首页榜单最多50条，标题、排名、播放量、点赞量及视频链接；标记为视频线索，未下载视频，`material_available=false`。
- 小红书热词：实验适配器，仅热词和搜索链接；2026-11-22实测HTTP 500，暂不可用，不生成占位数据。
- 抖音保持现有实现。所有来源行业和关键词暂不用于过滤。

新增来源可在「采集来源」添加、手动执行或设置定时采集，热点大厅显示具体平台。HTTP限制、业务失败、响应结构变化、非JSON响应均会记录失败；不使用仓库中的占位回退。

验证：真实接口抖音49条、微博50条、B站50条，小红书HTTP 500。这是接口探测结果，后台实际入库以日志为准。采集相关30项测试通过，Docker后端全量45项测试通过，前端构建通过。开发租户新增来源默认停用定时执行，首轮手动任务用于验证入库。

首轮后台入库核验：demo租户微博收到51条（过滤后50条），新增50条；B站收到50条，新增50条。数据库分别确认50条，共新增100条真实榜单线索。新增来源未启用定时执行。
